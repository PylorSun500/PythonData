# 常用技巧

## 字体

我们都知道，可以使用 `font-family` 来设置字体，但在一些字体管理混乱的操作系统中，不管是字体包名还是对应包的安装状态都很难确定，因此，我们可以通过注册字体文件的方式，来特定一个字体来使用。

```python
from matplotlib import font_manager
```

- 注册字体文件：

```python
fontpath = 'path/to/font.ttf'
font_manager.fontManager.addfont(fontpath)
```

- 获取字体名称：

```python
fontname = font_manager.fontProperties.get_font_names(fname = fontpath).get_name()
```

- 使用字体：

```python
plt.rcParams['font.family'] = [fontname]
plt.rcParams['axes.unicode_minus'] = False
```

## 生成字母序列
```python
# 生成小写字母a-e
tk = [chr(i) for i in range(97, 97+5)]  # ['a', 'b', 'c', 'd', 'e']

# 生成大写字母A-E
tk = [chr(i) for i in range(65, 65+5)]  # ['A', 'B', 'C', 'D', 'E']
```

这里使用了 Python 的 `chr()` 函数和 ASCII 码生成字母序列。<br>
使用列表推导式可以简洁地生成指定范围的字母列表，适用于需要 **自动生成类别标签** 的场景
- 小写字母 'a' 到 'z' 的 ASCII 码范围是 97 到 122
- 大写字母 'A' 到 'Z' 的 ASCII 码范围是 65 到 90

## 使用numpy数组
```python
import numpy as np

# 创建等间距数组
x = np.arange(5)  # [0, 1, 2, 3, 4]
y = np.array([12, 5, 15, 10, 6])  # 列表转数组
```

NumPy 数组比 Python 列表更适合数值计算。

- `np.arange(n)` 生成从 0 到 n-1 的整数序列，常用于 x 坐标
- `np.array()` 将 Python 列表转换为 NumPy 数组

NumPy 数组支持向量化操作，可以提高计算效率。使用 NumPy 数组可以使代码更简洁高效

## 同时处理多个柱形

```python
for bar in bars:
    height = bar.get_height()
    plt.text(bar.get_x() + bar.get_width()/2, height, str(height))
```

当需要为多个柱形添加相同样式的标签时，使用循环批量处理。遍历柱形对象容器，为每个柱形计算标签位置
- 标签的 x 位置通常取柱形中心：`bar.get_x() + bar.get_width()/2`
- 标签的 y 位置通常取柱形顶部：`bar.get_height()`

这种方法确保所有标签格式一致，位置准确
