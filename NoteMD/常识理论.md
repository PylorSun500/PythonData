## 图表元素设置

### 标题和坐标轴标签
```python
plt.title('图表标题')
plt.xlabel('X轴标签')
plt.ylabel('Y轴标签')
```

### 图例

有两种设置方式：

- 直接传入标签列表
- 绘制每个数据系列时通过 `label` 参数指定

推荐使用后者，代码更清晰且易于维护。但在此时，必须通过 `plt.legend()` 来渲染图例。

```python
plt.legend(['图例1', '图例2'])  # 直接指定
# 或者
plt.plot(x, y1, label='图例1') # 绘制时通过 label 参数指定
plt.plot(x, y2, label='图例2')
plt.legend()
```

### 坐标轴范围
```python
plt.xlim(0, 10)  # 设置x轴范围
plt.ylim(0, 20)  # 设置y轴范围
```


### 刻度标签

- 第一个参数是刻度的位置（一般是数值索引），第二个参数是对应的标签文本
- 可以用于将数字索引转换为有意义的类别名称

```python
# 设置x轴刻度标签
plt.xticks([1, 2, 3, 4, 5], ['25', '50', '75', '100', '125']) 
# 设置y轴刻度标签
plt.yticks([1, 2, 3, 4, 5], ['劣', '可', '良', '优', '特'])
```

## 图形窗口设置

### 图形大小

使用 `plt.figure(figsize=(width, height))` 在创建图表前设置图形大小，宽度和高度的单位是 **英寸** 。

```python
plt.figure(figsize=(10, 6))  # 宽10英寸，高6英寸
```

### 显示图形

确保所有绘图和设置操作都在 `plt.show()` 之前完成

```python
plt.show()  # 显示图形
```

## 数据标签方法

### 获取柱形对象属性

`plt.bar()` 返回一个包含所有柱形对象的容器，通过遍历这个容器可以访问每个柱形对象。

使用 `get_height()`、`get_x()`、`get_width()` 等方法获取柱形的几何属性

这些属性对于精确定位数据标签非常有用。

```python
bar = plt.bar(x, y)
height = bar.get_height()  # 获取柱形高度
x_pos = bar.get_x()        # 获取柱形x位置
width = bar.get_width()    # 获取柱形宽度
```

### 添加文本标签
```python
plt.text(x_pos, height, str(height), ha='center', va='bottom')
# ha: horizontal alignment ('center', 'left', 'right')
# va: vertical alignment ('bottom', 'top', 'center')
```

- 数据标签直接在柱形上显示数值，使图表信息更完整
- 使用 `plt.text(x, y, text)` 在指定位置添加文本
- `ha` 参数控制文本的水平对齐方式，`va` 参数控制垂直对齐方式
- 通常将标签放在柱形顶部中央位置，使用 `ha='center', va='bottom'`
- 可以根据需要调整标签位置，避免重叠或遮挡
